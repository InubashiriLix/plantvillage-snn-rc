- [ConvSNN38](convsnn38/metrics.json)：终版报告引用的 selection 与 final_test 指标，含原 metrics 文件相对路径和 SHA-256；理想与硬件感知分开列出。
- [ConvSNN Top10 论文绘图数据](convsnn10/README.md)：理想/硬件感知最终测试准确率 97.67% / 93.85%，包含逐类指标、混淆矩阵、完整训练曲线、8 步时间准确率及类别映射，已与逐样本预测核对。

- [RC10 v5](rc10/v5_results.json)：冻结测试 0.9702406079 / 0.9679804757，训练/验证/测试样本数 15162/3791/4738。类别基于此前 RC38 验证成绩筛选，不能与完整 38 类直接比较。
- [RC10 九路真实硬件，300 样本](rc10_hardware300/README.md)：三次完整嵌套五折平均准确率 83.44%，标准差 1.64 个百分点，宏 F1 83.23%；历史探索平均 90.44%。本轮没有确认提升。包含聚合指标、配对变化、冻结参数及 PNG/SVG 绘图，无独立测试集结果，与上述模拟 RC10 不直接比较。
- [九路实测硬件第二轮](rc10_hardware300_v2/README.md)：响应分布、L-BFGS 神经网络与树模型融合，三次准确率 91.00% / 92.00% / 89.00%，平均 90.67%。初始化扩展后为 91.33% / 92.33% / 89.00%，平均 90.89%，较第一轮高 7.44 个百分点，较历史探索高 0.44 个百分点，未证明稳定超越。自适应开发未完全嵌套，无独立测试集；两套结果及全部开发配置分别保留。
